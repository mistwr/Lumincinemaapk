# LUMIN AI Studio

Isolated Flutter Android development workspace. No production changes.

## Delivery gates
- [ ] Flutter analyze and tests passing
- [ ] Real image generation with authenticated backend (no client API secrets)
- [ ] Real video generation with asynchronous jobs, progress, retries and download
- [ ] Storyboard rendering and video assembly
- [ ] Supabase authentication and per-user project access
- [ ] Android APK built and installed on device
- [ ] Usage/cost limits, content safeguards and error handling

Do not advertise generation as working until tested end-to-end. CI scaffold is included in this branch.
